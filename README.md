# European Continent GeoParquet 

This is an attempt to create a geoparquet file of what is commonly called "Europe", not the European Union. 
The split between Europe and Asia is based on Sasha Trubetskoy's work. Find his reasoning here: https://sashamaps.net/docs/resources/europe-asia-boundary/

I include all processing scripts and files so you can rerun the script or modify it to your needs. Ran on 08/02/2026.
